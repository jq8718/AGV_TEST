参考：D:/XC/2026/P4SCAN/ESP32P4_XCF_OV9281，port/standalone_idf_test/main/scan_pose.c、scan_uart.c。

角点去畸变、单应性求解、双候选姿态与非线性精修、角度和距离的坐标定义沿用参考算法。内容首字符0/1/2分别选择有效码体边长30/50/70mm。算法此前已一致，本次补齐OV9281默认内参，使没有本机标定的OV9281也按参考默认参数输出位姿。

UART v6数据格式、CRC16/CCITT-FALSE、999→0帧号回绕、前导零保留、上电默认COMPACT、FULL切换和@CAL读写与参考一致。角度为毫度，距离为毫米，角点为像素×10。本板UART0 TX=GPIO43、RX=GPIO42、921600 8N1；参考板使用UART1 TX=GPIO41、RX=GPIO42。标定命令分辨率按当前传感器检查。STM32接收解析器C/H文件与参考一致。
